# Korpskonsert

Offline iPad web app for playing piano/organ with a wind band: shows chord symbols (besifring) measure by measure,
plays rehearsal recordings in sync, jumps to measures, shows sheet music with the current measure highlighted,
and lets you edit chords and sync.

Contains only the app code. Sheet music, chords and recordings are imported on the device from a local data file
(`.korps`) and stored in the browser's IndexedDB; nothing is uploaded.
